Three different exposures

## 6. Convergence can create carry

Convergence can create carry

Illustrative mechanics with a constant settlement level and no fees or collateral return.

Step / Value / Interpretation
Spot VIX at start / 15 / Reference level only
Front future purchased / 20 / Future trades above spot
Settlement SOQ / 15 / Contract converges to settlement
Futures return / −25% / (15 − 20) ÷ 20

The drag comes through price evolution and convergence.

The roll transaction itself does not create an instant cash loss.

## 7. A rolling index is not spot VIX

A rolling index is not spot VIX

The S&P short-term index maintains a constant one-month futures exposure.

Component / Index mechanic / Return effect
Nearby futures / Holds first and second maturities / Futures prices move
Daily roll / Shifts weight from M1 toward M2 / Exposure and convergence change
Collateral / Total-return version accrues Treasury return / Adds collateral income
Listed product / May add fees, leverage or daily reset / Can widen tracking difference

A change in spot VIX is only one input to the result.
